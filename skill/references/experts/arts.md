# 诗歌 / 视觉 / 实用生活档案（arts）

三类轻量处理：poetry（诗集/词集/散文诗）、visual（画册/摄影集/图像小说）、practical（菜谱/指南）。含**古典内容**（古典诗文、古文、古籍）的考据规范。

## poetry · 常驻专家组

### 1. 意象韵律分析师 → 02-analysis/imagery.md
- 框架：意象库（意象 → 出现篇目 → 含义场，横向对照意象的复现与演变）；音韵与形式分析（格律/自由体、分行节奏，中文诗注意平仄与对仗 [推断] 标注）；代表篇精读（选 3-5 首：逐联拆解）；诗人语汇指纹（高频词、偏好的隐喻结构）
- 批判轨：意象空转、为赋新词、译本失真问题（翻译诗必须注明所据译本，评价限定在译本层面）

### 2. 古典文献考据专家（古典诗文必配）→ 02-analysis/philology.md
- 框架：**创作背景考据**：每首/每篇的系年（约何时、何地、处境）[网络·来源]；**作品坐标系**（时空坐标卡，见 auditor.md——不放在安史之乱里读不出杜甫）；古今对照（古地名→今地名、古官职/制度→白话、典故出处）；版本源流（重要异文、选本差异，存在则注明）
- 批判轨：通行解读的以讹传讹、张冠李戴的典故、 pseudo-考据

## visual · 视觉主导轨道（画册 / 摄影集 / 设计集 / 绘本 / 图像小说）

**判定（step 1 提取后自动）**：全文提取 < 3000 字或页均文字 < 15 字 → 视觉主导轨道（visual 权重 ≥0.6）；图文参半（画册带长文论、展览图录）→ visual 副权重，双轨并行。

**视觉测绘官（必配，替代文本 mapper 为主图）**：多模态子 agent 分批读页（每 agent ≤20 页，骨架先行）→ `01-meta/book-map.md` 视觉版：作品登记表（作品名/创作者/年代/媒介）+ **视觉母题密度表**（母题 → 出现页码，概念密度的视觉对应物）+ 图注金句表 + 文字-图像比。信源体例：作品定位用 `[图版·p N]`，图注与正文文字仍 `[原文·L]`。

**常驻专家组（2-3 名）**：
1. **图像叙事分析师** → 02-analysis/visual.md：视觉语言（构图/色彩/线条的表意）、图文关系（互补/对位/反讽）、系列作品的连贯性。批判轨：图文互抢、风格失衡
2. **形式分析师**（视觉书必配）→ 02-analysis/form.md：构图语法 / 色彩系统 / 光线与材质 / 序列节奏（翻页的叙事）——把「视觉语言的论证链」拆出来（画家凭什么用这个构图说服你的眼睛）
3. **艺术史定位员**（画册/摄影集必配）→ 02-analysis/art-map.md：谱系（承谁启谁）、时期与风格定位、展览与收藏脉络 [网络·来源]；摄影集加**拍摄现场考据**（项目背景、年代语境，必要时时空坐标卡）

**文字稀缺的补偿**：视觉书调研权重加倍（step 1 调研 4 agent 照常 + 艺术史文献/作者访谈/展览评论成为主语境源）——信源降级标注照用（[网络·]/[推断·]，无原文纪律同样适用于图）。

**下游适配**：digest 全景 = 作品巡礼（代表作品逐一落点 + 母题演变线）；餐巾纸草图 = 视觉母题关系图；讲书脚本 = 「怎么看这本册子」的观展路线；takeaway 物料天然适配视觉书。视觉母题可入宇宙概念（domains 标视觉艺术，如「决定性瞬间」）。红队用 auditor 的 poetry/visual 清单（矫饰、空转、译本失真）。

## practical · 轻量处理（1 名）

- **可用性评估师** → 02-analysis/usability.md：步骤可执行性（能否照着做成功，缺哪步）、适用边界（器材/食材/场地门槛）、安全性核查（涉及健康/安全的论断须核实 [网络·来源]）。批判轨：伪需求步骤、不验之方。此类书可省略 step 3 的图谱，产出「操作要点速查表」替代。

## 最终产出差异

- 书评重点：审美体验 + 作品与时代的互文 + 精读示例带来的"看懂了"时刻
- 额外产出：**意象/作品延伸单**（同诗人他作、同流派他人、受其影响者——外延 + 宇宙内联两栏）；practical 类给操作速查表
- 餐巾纸：一句话 = 这组作品的灵魂；公式 = 诗人/作者的表达模型（意象 × 情感 × 形式）；草图 = 意象关系或作品坐标 Mermaid
