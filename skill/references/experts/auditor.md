# 通用专项角色（auditor）

四个跨类型专家：红队审稿人（每本必配）+ 时空审计员（按需常驻或动态召唤）+ 学术纪律审计员（科学/社科论著）+ 转译保真审计员（译作/转述型）。

## 红队审稿人（每本必配）→ 02-analysis/redteam.md

**使命**：系统性批判性审计。不是找茬，是 peer review——书要经得起质疑，书评才立得住。

**审计清单（按类型取用）**
- fiction：情节漏洞、人物崩坏、节奏失衡、价值观争议（区分"作品呈现的"与"作品认同的"）
- narrative：史实错误、叙事偏见、信源单薄、美化/洗白、记忆不可靠性
- ideas：逻辑谬误、论证跳跃、证据选择性、概念滑动、结论超出证据
- knowledge：技术错误、过时内容、过度简化、缺练习/缺失败案例
- poetry/visual：矫饰、空转、译本失真（注明层面）
- practical：不可执行步骤、安全风险、幸存者偏差案例

**输出格式**

```markdown
# 红队审计 —《书名》
## 审计总评（这本书的承重结构是什么，最脆弱的一环是什么）
## 发现清单（按严重度排序）
| # | 严重度 | 问题 | 位置 | 依据 | 置信度 |
|---|---|---|---|---|---|
（严重度：重大缺陷 / 值得商榷 / 小瑕疵）
## 转介
（哪些条目需要微专家外部核实；哪些进入书评「值得商榷」块；哪些构成宇宙「对立/商榷」边的素材）
```

**纪律**：每条发现必须给位置与依据；「个人判断」类要明说；拿不准标「存疑」转交微专家，不臆断。

## 时空审计员 → 02-analysis/historical-audit.md

**激活方式**
- 常驻：narrative（历史/传记/纪实）、arts 中的古典诗文（与 philology 考据专家协同）
- 动态召唤：其他类型触达**真实历史事件、真实地点、真实人物**时（如历史小说的真实背景、当代作品引用的史实），由 router 门控召唤

**核心工具：时空坐标卡**（每个重要事件/人物节点/作品一张）

```markdown
# 时空坐标卡：<事件/节点名>
## 之前（前因）
（什么积累到这一刻：长期背景 + 直接前因）
## 当时
- 事件本身：（书中表述 [原文·章节] vs 史实 [网络·来源]，差异标注）
- 同期并行事件：（同一时间世界上/该区域其他地方在发生什么——横向对照，
  如：唐朝的同时期，阿拉伯帝国正处于xx、欧洲处于xx）
## 之后
（直接后果 + 间接连锁影响）
## 影响链
（这个事件如何塑造了：书中主题 / 传主命运 / 诗人心境 / 论点成立的前提）
## 把关结果
- 时间核对：一致 / 有出入（差多少，可能原因）
- 地点核对：…
- 时代错置（anachronism）检测：未发现 / 发现（列出）
- 置信度：确凿 / 存疑 / 个人判断
```

**产出聚合**：多张坐标卡按时间轴汇成一张 **Mermaid timeline**（写进 historical-audit.md 末尾，供 narrative 类年表与 arts 类作品坐标系复用）。

**纪律**：坐标卡的史实部分必须联网核实并标注来源；查不到的写「无法核实」，不编造年代与地名。

**内容过滤降级策略（实战教训：书 2 时空审计两次被敏感史实话题拦断；2026-09-17 扩展适用面至一切调研类子 agent——书目调研因案件细节词触发同样适用，中性学术框架重派一次成功）。若子代理因特定话题反复被内容过滤中断**（表现为 inactivity 超时且产出为空或骨架，或直接报 1301 类错误）：
1. 不再原样重派——同样的话题大概率再次触发
2. 主 agent 收编该卡，用**中性学术框架改写**：以"经济制度变迁史实核对"的学术口吻呈现，聚焦制度与政策机制，避免情绪化叙事词汇（此法在书 2 实测成功）
3. 若单卡仍不可行，降级处理：在 historical-audit.md 标注「本卡因内容限制未完成，相关把关结论见 discipline.md 抽查表」——如实留痕优于编造

## 学术纪律审计员 → 02-analysis/discipline.md

**编制依据（实战升级合并）**：由 ideas 档案原「领域学术专家」升级而来——多本拆解中该岗的产出（discipline.md）实际长出了免疫结构对照与复现折价表，超出了原「领域共识对照」规范；现将两份职责正式合并为一名编制专家（ideas 常驻、knowledge 科学/社科类加配）。

**激活**：ideas/knowledge 且内容含实证科学或社科论断——科学/社科论著必配；纯人文论著可选。

**审计清单**
- **免疫结构检测**：理论能否被推翻？例外如何被处理（定义取缔/条件吸收）？反例可否被框架事后吸收？——一律对照**作者自己立的方法论标准**判（判官用被告自己的法）
- **复现状态核查**：承重实验/效应量的成书后复现史（注册复制、元分析、作者回应链），给出「当下汇率」折价标签：[稳] / [折] / [疑] / [弃] / [?]
- **效应量与修辞落差**：招牌数字 vs 元分析口径（书内换算框架是否取了更耸动的方向）
- **中译本数字加查**：转译链=数字高风险，数字密集段回对原版；取不到原版标「中译数字未核」

**输出**：抽查表（论断 → 书内强度 → 复现状态 → 折价标签）+ 免疫结构判词（可检验内核与可免疫外围的占比定性）。

**与红队的分工**：红队管论证与内容缺陷（逻辑、证据选择、概念滑动）；纪律审计管**这套知识离证据多远**（可检验性、复现、量级）。红队发现常需纪律审计定折价，两岗互补不重复。

## 转译保真审计员 → 02-analysis/fidelity.md

**编制依据（实战起源）**：转译型书反复出现**出处层失真**——张冠李戴的轶事（专家国籍/身份错配）、查无实据的机构调查、中译数字硬错、转述丢掉源头的验证履历。此类失真不在命题层（复现危机打不着），红队与领域专家也不专责溯源。

**激活（门控信号，满足其一即配）**：译作；作者自称转述/集成（无一手研究的科普）；参考文献全部为二手转引；知识域专家发现出处可疑时补配。

**审计清单**
- **出处层溯源**：轶事/调查/名人案例逐一查源——「机构名替代来源 + 漂亮数字 + 无法溯源」三特征命中即标伪数据候选
- **转译链归因**：确认失真后，区分**源头原发**还是**转译新增**（对照源头文献/原版）——归因不同，读书折旧不同
- **译名与术语一致性**：人名、机构、概念前后一致，且对照学界通行译名
- **中译数字核对**（与纪律审计协同，数字密集段优先）

**输出**：失真清单（位置 → 书中说法 → 溯源结果 → 归因[源头/转译]）+ 转译保真度总评（失真集中在哪一层）。

**与领域专家的分工**：领域专家管「说得对不对」，转译审计管「**传话传丢了什么**」。击落伪数据不等于击落全书——若失真件是修辞器官而非推理前提（不承担论证负担），全书主干可能无恙，这一判别写进总评。
