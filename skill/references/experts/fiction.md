# 虚构叙事档案（fiction）

小说、短篇集、戏剧、类型小说（科幻/推理/历史/武侠/言情）。核心问题：**这个故事是怎么讲好的，讲的是什么**。

## 常驻专家组（子 agent prompt 模板）

每个专家的 prompt 骨架：`你是<角色>。<使命>。输入：00-source/fulltext.md 与 01-meta/ 各文件（按需）。输出写到 02-analysis/<文件名>，格式见下。遵守信源标注规则，每段产出分「正向解析」「批判指摘」两轨。`

### 1. 叙事结构学家 → 02-analysis/structure.md
- 使命：拆解故事的骨架与节奏
- 框架：整体结构模型（三幕/环形/多线并置…，注明判断依据）；**情节节拍表**（按章节/幕列：事件、功能、张力值升或降）；**起停转折点**（转折在哪、铺垫在哪、是否公平）；**故事线矩阵**（单线或每条线：主线/副线，各线的起止、交叉点、相互影响——谁改变了谁）
- 批判轨：节奏失衡处、烂尾/虎头蛇尾、为反转而反转

### 2. 人物关系分析师 → 02-analysis/characters.md
- 使命：人物图谱、**人物档案册**与时间线
- 框架：
  1. **人物关系 Mermaid 图**（graph 节点=人物，边标注关系性质：亲缘/对抗/暗恋/镜像…）
  2. **人物设定卡**（每个主要角色一张；门控：有独立弧线或推动关键剧情者入档，龙套不建档。群像小说按角色分卡、可拆多个子 agent 并行，骨架先行防卡死）：
     - 身份与阵营 / 出场范围（首次出场 → 退场或收尾）
     - **样貌·神态·服饰**：首次出场的完整描写（原句摘引）+ 后续显著变化——服饰与神态的变迁常标志境遇、地位或心境转折，逐处带 [原文·行号]
     - **人物事件线**（按故事内时间排序）：主要事件 → 章节定位 → 对该人物的意义（表格或 Mermaid timeline）
     - 弧光一句话：起点状态 → 终点状态（转变是否可信留给批判轨）
  3. **全书事件时间线**（characters.md 末尾）：由各人物事件线交叉汇总成书级时间线——按**故事内时序**排列关键节点（生死、结盟背叛、转折），并标注**叙事顺序 vs 故事时序**的差异（倒叙/插叙/多线并置处点名，回馈给叙事结构学家）
  4. 人物功能分析（主角/镜像人物/催化剂…）；跨书人物原型备注（若宇宙已有类似原型，标注"参见 universe/concepts/xxx"）
- 批判轨：工具人、人设崩坏点（与设定卡的样貌/行为对照）、动机不足处

### 3. 文体语言分析师 → 02-analysis/style.md
- 使命：语言怎么服务于故事
- 框架：语域与句法特征（举原文短例）；叙事视角及其切换；对话/描写/叙述的配比与功能；**可学习的写作技法**（每条：技法名 + 原文示例 + 仿写要点）
- 批判轨：翻译腔/腔调问题、滥修辞、失效的视角

### 4. 主题象征分析师 → 02-analysis/themes.md
- 使命：故事的灵魂层
- 框架：核心主题（不超过 3 个，每个附 2-3 处文本证据）；意象与象征系统（意象表：出现位置→含义演变）；题眼（书名/题记/复现句的解释）
- 批判轨：主题先行、说教感、象征过载

### 类型加成（命中才激活）
- 推理悬疑：**诡计公平性审核**（线索是否前置、解答是否成立）
- 科幻/奇幻：**设定自洽性审核**（设定规则是否自我一致，硬伤清单）
- 历史小说：时空审计员升级为常驻（见 auditor.md）

## 双轨产出格式（每位专家统一）

```markdown
# <专家名> —《书名》
## 正向解析
（框架内容，论断标注 [原文·章节]）
## 批判指摘
（每条：问题 + 位置 + 依据 + 置信度[确凿/存疑/个人判断]）
## 可迁移
（这个专家视角下，读者能带走什么）
```

## Step 3 综合模板（03-synthesis/level1.md）

```markdown
# 《书名》Level 1 泛化
## 一段话总结（这本书是什么）
## 故事体系图（Mermaid：主线+副线+交叉点）
## 人物体系（图谱精简版 + 弧光一览表）
## 主题与灵魂（≤3 个主题 + 题眼）
## 叙事技法清单（可学习项，供写作参考）
## 批判对照表（红队+各专家挑错汇总，按严重度排序）
## 涌现合成观点候选（若有宇宙碰撞：观点 + 来源书目组合 + 标注「涌现，待用户裁决」）
```

## 最终产出差异（step 5/6 时遵循）

- 书评重点：故事体验 + 叙事技法 + 主题共振；红队「值得商榷」块不可省
- 额外产出：**同氛围书单**（题材/主题/叙事风格相近，含外延与宇宙内联两栏）；characters.md 的人物设定卡与全书时间线是书评/talk-script 的素材库（讲书必备人物，时间线防口播时序错置），也直接服务二创与改编场景
- 餐巾纸：一句话 = 故事内核；公式 = 主角 × 欲望 × 障碍 × 代价；草图 = 故事线 Mermaid
