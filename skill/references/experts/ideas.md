# 思想论述档案（ideas）

哲学、社科、科普、商业管理、评论。核心问题：**作者主张什么，论证成立吗，在思想地图上处在什么位置**。

## 常驻专家组

### 1. 论证分析师 → 02-analysis/argument.md
- 使命：把全书论证拆成可检验的结构
- 框架：**论点树**（中心论点 → 分论点 → 支撑证据，Mermaid 或缩进树）；**论证链条图**（每条链：前提 → 推理 → 结论，标注推理类型：归纳/演绎/类比/因果）；核心概念词典（作者自定义或重定义的词：定义 + 用法 + 与日常用法的差异）；论证强度自评（哪些链是硬支撑，哪些是软联想）
- 批判轨：逻辑谬误点名（稻草人/滑坡/幸存者偏差…，每处给原文位置）、证据 cherry-picking、概念滑动

### 2. 学术纪律审计员（原「领域学术专家」，实战升级合并）→ 02-analysis/discipline.md
- 使命：以学科专业标准 + 证据纪律双重审视全书（领域由分类卡确定；跨学科书按章节分派微专家）
- 完整规范见 auditor.md——四件事：① 书中论断 vs 学科共识（一致/超前/争议/已被修正，附来源）；② 免疫结构检测（对照作者自己的方法论标准）；③ 复现状态核查与折价标签 [稳]/[折]/[疑]/[弃]；④ 中译本数字加查
- 批判轨：过时结论、对研究的过度引申、外行误读、不可检验的全称断言

### 3. 思想史定位员 → 02-analysis/intellectual-map.md
- 使命：把书放回思想谱系
- 框架：作者的思想坐标（继承谁、反对谁、综合谁）；该领域的问题脉络（这本书回应什么老问题、开了什么新问题）；与宇宙已有思想类书籍的谱系连线（"参见 universe/concepts/xxx"）
- 批判轨：树错靶子、把已有思想包装成原创

### 4. 反方辩手 → 02-analysis/opposition.md
- 使命：**steelman**——构造最强的反对论证（不是抬杠）
- 框架：反方最佳论证（3-5 条，每条：论点 → 论据 → 与原书的交锋点）；**共同体外反方至少 1 条（先贤评审 2026-09-18 补）**——不止从本书学术共同体内部找对手，至少 1 条来自伦理/政治/实践立场的反对（例：给行为经济学当反方的除了计量心理学家，还应有市场社会的伦理批评者）；作者可能的回击；裁决表（每个交锋点：谁占理、置信度、开放性）
- 输出不分双轨——本专家整体就是批判轨，但仍须公平：steelman 反方同时如实呈现作者最强处

## 双轨产出格式
同 fiction.md 统一格式；反方辩手除外（见上）。

## Step 3 综合模板（03-synthesis/level1.md）

```markdown
# 《书名》Level 1 泛化
## 一段话总结（作者主张一句话 + 论证策略一句话）
## 思想地图（Mermaid：中心论点+分论点+证据层）
## 核心概念词典
## 论证链可靠性评级（硬/中/软，附主要软肋）
## 正反对照表（原书 vs 反方辩手，逐交锋点裁决）
## 在思想谱系中的位置（继承/反对/综合 + 相关书连线）
## 思维模型卡（这本书贡献的可复用思维工具，每张：模型名+适用场景+失效场景）
## 批判对照表
## 涌现合成观点候选
```

## 最终产出差异

- 书评重点：思想的可取处 + 论证的可靠度 + 对读者既有观念的冲击；正反对照写进「值得商榷」块
- 额外产出：**对话书单**（同意/反对/推进这本书的三类书）——外延 + 宇宙内联两栏
- 餐巾纸：一句话 = 核心主张；公式 = 核心思维模型（如 系统 = 要素 × 连接 × 功能）；草图 = 思想地图精简版
