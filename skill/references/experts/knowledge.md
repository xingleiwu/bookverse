# 知识技能档案（knowledge）

教材、技术书、方法论、自助成长、工具书。核心问题：**知识体系长什么样，怎么学会，学完能做什么**。

## 常驻专家组

### 1. 领域专家（**动态实例化岗位，非静态存在**）→ 02-analysis/domain.md
- **本岗是按书定制的模板**：不存在通用的「领域专家」，只存在被实例化为某学科专家的领域专家。实战三例分别是脑科学、认知成长、法律实务三个完全不同的岗位。配置流程（确认点 A 前完成，画像写进激活清单）：
  1. **领域画像**：分类卡主学科 + 正文内容信号（议题/知识点清单）→ 学科名 + 子领域 + 该领域的评估基准（教科书 / 学会指南 / 系统综述，哪一层算「共识」由学科惯例决定）
  2. **跨学科书**：主域必配；副域类型权重或内容占比 ≥0.3 时加配副域节（domain.md 单档分节，不拆文件）；更细的第三域知识点缺口走微专家召唤，**不为此扩编第三位领域专家**
  3. **prompt 按画像定制**：该领域的核查源习惯（综述 / 预注册 / 实务惯例）、时效基准（该学科知识更新速度——脑科学与法学的「过时」标准不同）、共同体评价这类书的常用尺度
- domain.md 头部标注「领域画像：本岗为〈学科·子域〉实例化」——让读者知道这版评估站在哪个学科的肩膀上
- 使命：以（实例化后的）领域标准评估知识内容的准确性、深度、时效
- 框架：知识准确性抽查（关键结论 vs 领域共识，附来源）；内容深度定位（入门/进阶/专家，判断依据）；时效评估（哪些内容有过时风险及原因）；本书在领域内的位置与口碑 [网络·来源]
- 批判轨：技术性错误、过时实践仍当最佳实践、为通俗而失真
- **中译本书加查**：数字引用必须回对原版/原始文献——转译链=数字高风险（实战：某中译方法论书实测 3 处数字硬错且全在关键论证带：7410→7401/740、1 万→10 万）；抽查时对数字密集段做原版抽查，无法取原版则标注「中译数字未核」
- **与学术纪律审计员分工**（科学/社科类 knowledge 书两者同配时）：本岗管「内容对不对、深不深、新不新」（domain.md）；纪律审计管「离证据多远、能否被检验」（discipline.md）——各自档案，不合并

### 2. 课程设计师 → 02-analysis/curriculum.md
- **适用面（实战收紧）**：仅当书本身是学习路径型（方法论、教材、技能训练）才配；通识问答集、观念普及、工具书跳过本岗（实战：问答集类正确跳过，学习类 6/6 全配）
- 使命：把书转成可执行的学习路径
- 框架：**知识体系图谱**（Mermaid：领域地图中本书覆盖的范围 + 前置知识节点 + 后续延伸节点）；**前置知识清单**（每项：是什么、要补到什么程度、推荐补法）；**学习路径**（依赖排序的章节学习序列，标注可跳过项与精读项）；与宇宙已有知识类书的体系衔接（"学过《X》的可以直接读第 N 部分"）
- 批判轨：章节依赖混乱、缺少练习、难度跳跃

### 3. 实践教练 → 02-analysis/practice.md
- 使命：让知识落地
- 框架：**应用场景清单**（每个知识点：什么时候用得上，给 1-2 个具体场景）；**练习设计**（每章 1-2 个可动手的练习/项目，附自检标准）；常见新手坑（从书中要点推演 + 网络实践社区反馈 [网络·来源]）
- 批判轨：纸上谈兵处、缺少失败案例、鸡汤化（自助类常见）

### 变体
- 工具书/手册：课程设计师 → 换为**检索效率分析师**（查询路径是否合理、索引质量、速查表设计）

## 双轨产出格式
同 fiction.md 统一格式。

## Step 3 综合模板（03-synthesis/level1.md）

```markdown
# 《书名》Level 1 泛化
## 一段话总结（这本书教会什么，适合谁，不适合谁）
## 知识体系图谱（Mermaid）
## 学习路径（精读/略读/跳过标注 + 前置知识）
## 核心知识卡（每张：知识点+一句话+应用场景，供速查表与宇宙概念节点复用）
## 练习清单（动手项 + 自检标准）
## 可信度与时效（抽查结论 + 过时风险清单）
## 批判对照表
## 涌现合成观点候选
```

## 最终产出差异

- 书评重点：学习价值判断 + 适合人群 + 与同类书的比较定位；「值得商榷」块偏技术性纠错
- 额外产出：**cheatsheet 速查表**（06-takeaway/ 或 03-synthesis/，决策表+公式+命令式要点）+ **后续学习书单**（外延 + 宇宙内联两栏）
- 餐巾纸：一句话 = 这本书的核心方法论；公式 = 领域核心模型；草图 = 知识体系图谱精简版
