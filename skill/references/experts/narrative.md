# 非虚构叙事档案（narrative）

传记、回忆录、纪实文学、历史、旅行文学、随笔。核心问题：**真实发生了什么，作者讲得可靠吗，我们能看到什么时代与人**。

## 常驻专家组

### 1. 叙事记者 → 02-analysis/narrative-craft.md
- 使命：作者怎么把真实素材组织成叙事
- 框架：叙事策略（时间线处理、视角选择、场景重建的手法）；素材组织（编年/主题/双线…）；可学习的非虚构写作技法（场景化、细节选取、克制与张力）
- 批判轨：煽情操纵、戏剧化失实、剪裁引导

### 2. 史实核查员 → 02-analysis/fact-check.md
- 使命：书中的事实性论断抽查核实
- 框架：**事实抽查表**（挑 8-15 条关键论断：书中说法 → 核实结果 [网络·来源] → 一致/有出入/无法核实）；存疑论断转交红队或触发微专家
- 批判轨：与公开记录冲突的点、数据来源不明处

### 3. 史学把关人 → 02-analysis/historical-audit.md
- 使命：把书中事件放进历史坐标系（详见 auditor.md 时空坐标卡）
- 框架：书内主要事件的**时空坐标卡集**；事件之间的因果链梳理；书中叙事与主流史学表述的差异点
- 批判轨：时代错置、单因解释、胜负者视角

### 4. 传主研究者（传记/回忆录类）→ 02-analysis/subject.md
- 使命：这个人是谁，作者为什么这样讲他/自己
- 框架：**人生年表**（关键节点 + 每节点一个决策点）；**人生决策点分析**（当时处境 → 选项 → 实际选择 → 后果 → 若无此选择的历史可能性，标注[推断]）；作者与传主的关系及立场偏差（自传：自我叙述的修饰模式）
- 批判轨：美化/洗白/过度揭秘、记忆的不可靠性标注

### 变体
- 历史著作：传主研究者 → 换为**时代结构分析师**（制度/经济/社会结构如何推动事件）
- 旅行文学/随笔：传主研究者 → 换为**地方志观察员**（地方的真实肌理 vs 作者滤镜）

## 双轨产出格式
同 fiction.md 的统一格式（正向解析 / 批判指摘 / 可迁移）。

## Step 3 综合模板（03-synthesis/level1.md）

```markdown
# 《书名》Level 1 泛化
## 一段话总结
## 事件年表（书中事件 + 时空坐标标注）
## 人物（传主）决策点分析
## 时代坐标（这段历史/这段人生嵌在什么大结构里）
## 可信度评级（史实核查汇总：可靠/基本可靠/需交叉验证）
## 非虚构写作技法清单
## 批判对照表
## 涌现合成观点候选
```

## 最终产出差异

- 书评重点：故事 + 人物 + 可信度判断 + 时代意义；把「值得商榷」写成价值而非伤疤
- 额外产出：**延伸历史书单**（同事件不同视角、同时代其他面相）——外延 + 宇宙内联两栏
- 餐巾纸：一句话 = 这段真实故事的本质；公式 = 人物 × 时代 × 选择；草图 = 年表 Mermaid timeline
