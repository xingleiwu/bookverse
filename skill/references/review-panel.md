# Takeaway 评审组（Step 6 质量闸门）

每个 takeaway 产物（napkin / brief / principles / xhs / moments / talk / handbook）初稿完成后，**必须**过三角色评审组，全部 PASS 才算完成——先于标点检查，先于交付。用户说「全自动」时评审不省略，只静默执行。

书评（step 5 产物）不跑本评审组：确认点 B 的人工逐段确认已是最强评审，且反 AI 腔条款已内置于润色 spec。**例外——批量拆解模式**：确认点 B 被跳过时书评出现评审空窗，须并入评审组做**事实核对型轻审**（只查数字、引文、机制方向与底稿一致性，不查风格——风格无人工信号可依）；意见同样落盘 review-log。书评的事实核对可与 takeaway 合审同派（实测 2026-09-17：评审组抓出 digest 层传播的机制反向/数字锚点错误，是批量模式的最后防线）。

**合审配置**（2026-09-17 成本实测固化）：短产物（napkin/moments/xhs）合派一个子 agent、brief/principles 一组、talk/handbook 一组，或 7 产物单 agent 合审——每产物三角色意见仍须分列。合审成本 0.05-0.2M/本（占全书 1-2%），远低于逐产物单派。

## 评审协议

1. 产物初稿完成（未跑标点检查的版本）
2. **派评审子 agent，小批进行（单消息并行 ≤3 个；2026-09-17 实战：大批派单因 600 秒不活跃超时大量折损）**。产物多时分多轮派；子 agent 通道整批不可用时，降级为主 agent 分角色自评审（三角色意见仍须分列，并在 review-log 标注「自评审」）。短产物（moments、napkin）可两三个合派一个子 agent，但三角色意见必须分列。prompt 自带完整上下文：书名与类型、产物文件路径、digest.md 路径、本文本对应角色的档案、输出格式
3. 评审输出三份意见，各给裁决：
   - **PASS**：可交付
   - **FIX**：具体到句，给改法（原句 → 建议）
   - **FAIL**：需重写，给理由与方向
4. 主 agent 逐条处置：FIX 修改后对照意见自查关闭；FAIL 重写后**必须复审**（再派同规格评审）
5. 三角色全 PASS → `check_punctuation.py` → 交付
6. 意见落盘 `06-takeaway/review-log.md`：每产物三角色意见摘要 + 处置结果（采纳/否决及理由），供复盘与人格信号

## 角色一 · 内容质量专家（所有产物必含）

对照 digest.md 与 level1.md 逐项查：

- **忠实性**：事实、数字、引文、出处是否准确；无原文依据的内容不得出现
- **压缩失真**：限定句是否被压没了（「有时」变「总是」、「部分研究」变「研究证明」）；红队标注的争议是否被抹平
- **完整性**：该产物的必含元素是否齐全（brief 的 frontmatter 字段、principles 的失效场景、talk 的四层结构…）
- **可回溯**：关键论断是否可回溯到 [原文·章节] 或 level1 条目

## 角色二 · 渠道/产物专家（按产物类型查表）

| 产物 | 专家 | 关注点 |
|---|---|---|
| napkin | 记忆设计师 | 一句话能否被复述；公式是否真概括全书（套别的书也成立的公式是废的）；钩子是否具体（数字/场景），不是口号 |
| brief | 知识管理者 | frontmatter 字段完整可机读；五段齐全；引用可查；concepts 与宇宙概念节点对齐 |
| principles | 行为设计教练 | 条件可识别（真实场景能触发）；行动可执行（明天就能做）；失效场景真实不敷衍（「注意分寸」式废话不算） |
| xhs | 小红书内容运营 | 前两行在信息流里站得住吗；真实口语不假嗨；emoji 克制；标签规则逐条核对（10 个、领域精准、无泛流量/限流雷区）；无绝对化断言；版本信息行（出版社/丛书编号/装帧）对收藏型读者是检索词——默认不写，用户要求时以一行纯陈述给出 |
| moments | 朋友圈观察者 | 像真人随手发的吗；有细节或态度；不装；结尾不升华 |
| talk | 口播教练 | 300 字 ≈ 60 秒匹配；有气口；坡道 3 秒抓耳；说人话不播音腔；论点各配案例；结尾开放不总结 |
| handbook | 教学设计师 | 路径依赖排序正确；概念卡自足（不看别处能懂）；练习带自检标准；难度地形真实 |

## 角色三 · 去AI味专家（每个评审组必含，强制，一票可否决）

产出物但凡命中下列任一类，且说不出保留理由，判 FIX 或 FAIL：

**句式八股**
- 排比三连、对仗金句（「打上去是心，解开来是绳」类）
- 「不是 X，而是 Y」滥用；「不仅仅是 X，更是 Y」递进堆叠
- 「首先/其次/最后」「总而言之/综上」路标词
- 破折号解释展开、冒号后变相展开总结

**词汇雷区**
- 赋能、闭环、抓手、底层逻辑、顶流、王炸、天花板（滥用义）、破局、深耕、无痛、纯干货、建议收藏、入坑不亏、神作、宝藏（书）
- 「值得一读」「推荐给每一个人」类空评语

**结构八股**
- 总-分-总闭环、每段等长、bullet 山、结尾升华教益句
- 标题党；「一句话读懂 XX」式收束

**人味检测**
- 具体细节（数字、场景、人名、书页）够不够——只有真读过才写得出的细节至少一处
- 长短句是否错落，还是匀速滑行
- 删掉书名后还像人话吗

**渠道变体**
- xhs：假嗨跟风语（「姐妹们！」「真的会谢」）、堆 emoji、标签墙
- moments：装腔文艺腔、金句感过重
- talk：播音腔、朗读腔、书面语直读

## 降级与成本

- 评审子 agent 只读产物 + digest（+ 必要时 level1 对应节），不通读全档——单产物评审控制在轻量上下文
- 批量小产物合派；重写复审只针对 FAIL 的产物，不全员重审
