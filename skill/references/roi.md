# Step ROI · 阅读投入产出报表

度量阅读投入与产出，按主题域排名，指导后续投入方向。**只盘点、不采集**——所有数据在宇宙与工作区里现成躺着，本 step 不派子 agent、不联网。

## 触发

- 用户说「/bookverse roi」「算算阅读回报」
- 每次 Dream 报告第五步的标准组成（Dream 内嵌 ROI 节，单独报表也按本文件出）

## 数据源（全部现成，无新采集）

| 数据源 | 取什么 | 缺失处理 |
|---|---|---|
| `universe/books/*.md` frontmatter | `cost`（每本 token 成本）、`domain`（分域） | 缺 cost 记「未计量」，**不倒推估算**——RETRO-001 问题 2 的旧账用标注偿还，不用假数字掩盖 |
| `universe/LIBRARY.md` | 总览统计 + 概念域索引（域→概念清单，域聚合计数的权威来源） | — |
| `universe/graph/edges.jsonl` | 边计数、每本书作为 source/target 的出现次数 | 无边书 = 孤岛信号 |
| `universe/emergent.md` | 涌现候选的采纳 / 拒绝计数 | — |
| `universe/persona/profile.md` | 思想立场表：各来源书的立场行数 | — |
| `universe/persona/journal.md` | 转变候选的兑现记录 | — |
| `books/<slug>/06-takeaway/` | 各书物料实际件数（napkin/brief/principles/xhs/moments/talk/handbook） | — |

实战注记：域概念计数以 LIBRARY.md 概念域索引为准，不要人工盘点（2026-09-18 教训：经济学域 13 个概念靠人工盘点才发现批量期漏报）。

## 计算口径

**输入侧** = token 成本：每本 `cost`，按 `domain` 聚合为域累计；缺失计「未计量」栏，不并入合计稀释有数据的域。

**输出侧**（六项指标，全部可机器统计）：

| 指标 | 口径 |
|---|---|
| 概念增量 | 该域书目贡献的概念节点数；在既有概念对照表**加行**不计入——防靠重复挂靠虚增 |
| 边增量 | 该域书目建立的总边数，**书→概念与书↔书分计**——前者是消化深度，后者是网络密度 |
| 涌现采纳 | emergent.md 中来源含该域书目的已采纳候选数（拒绝数并列展示，不算产出） |
| 立场贡献 | 思想立场表中来源为该域书目的行数 |
| 物料 | 06-takeaway/ 实际存在件数 |
| 跨书被引用度 | 该书在 edges.jsonl 中作为 source 或 target 出现的总次数——这本书对宇宙其余部分的存在感 |

## 产出：`universe/records/roi/roi-<日期>.md`

主 agent 写（宇宙写入纪律：只有主 agent 写 universe/）。三段结构：

**① 按域 ROI 表**

| 域 | 书数 | 累计成本 | 概念增量 | 边 | 涌现 | 立场贡献 | 物料 | 被引用度 |
|---|---|---|---|---|---|---|---|---|

边列内部分计展示，如「12（书→概念 9 / 书↔书 3）」。

**② 全宇宙汇总一行**：各列合计；成本列附「未计量 N 本」。

**③ 投入建议**（报表的真正目的，三问三答）：

- **哪个域边际回报最高**：产出/成本比领先且概念未收敛 → 值得继续深挖，frontier 该域书单优先排期
- **哪个域饱和**：同类书概念重复率高（近期新书的概念增量与边增量持续走低）→ 同域下一本降档轻拆或暂停
- **哪个域是孤岛**：投入未产生连线（域内被引用度、书↔书边近零）→ 找桥书（未来某本能同时够到两座岛），或承认这段投入只服务了当时

## 诚实条款

- **MCP 对话引用次数暂无埋点**：brief.md 被 MCP 引用多少次测不到，相关结论一律标「未计量」，不编数。
- **被引用度带结构性偏差（先拆优势）**：早期书靠「后来者默认挂靠」积累度数（见 universe.md 边权与挂靠原则）；跨域比较前先看 Dream 合并审计对挂靠偏早的修正结果。
- **ROI 是启发式排序不是精确会计**：概念质量不均——一个「黑暗森林」级概念与一个平庸概念在表里都是 1；成本受书厚与拆解档位影响，不全是域的属性。**数字只用于提出问题，结论需人工复核**——报表给的是「哪里值得再看一眼」，不是「该读什么」的终审。

## 与转变候选的关系

成本算投入，**转变候选（persona 流程，见 persona.md Step 7）算最重产出**——偏好信号只度量口味，转变候选度量转化；一个高概念增量但零转变的域，产出含金量要打问号。报表末尾列 journal 中**已兑现的转变候选清单**（书目 → 候选 → 兑现记录），作为数字报表之外的定性证据。
