# Step 3b · 全书总结 digest.md（十碗水煎成一碗水）

## 定位与动机

level1.md 是多专家拼接的**分析工作台**——对照表、可靠性清单、免疫结构、mermaid 都是给查证用的，杂是特性不是缺陷。但它不能直接喂给书评和 takeaway：书评从它取材显得散乱，压缩类产物从它取材丢三落四。

digest.md 是对 level1 的**梳理与再思考**：把整本书精炼成一篇可独立阅读的叙述版全书总结。它是书评与全部 takeaway 的共同基础——书评从中选点深打，takeaway 从中压缩变形，细节再回 level1 / 02-analysis 查证。

## 与相邻产物的边界（防职责混淆）

| 产物 | 职责 | 关系 |
|---|---|---|
| level1.md | 分析工作台：全量证据与批判，给查证 | digest 的原料 |
| **digest.md** | 叙述版全书总结：重要内容全覆盖，给人读 | 对 level1 重组提炼，不是删减排版 |
| 书评 final.md | 选点深打：最重要/经典/有价值的几处 + 人格底色 | 从 digest 摘取，不求全 |
| brief.md | 结构化数据源（MCP 引用） | 从 digest 再压缩成表 |

## 篇幅与覆盖率

- 默认 **2000-5000 字**，按书的规模与密度浮动（参考锚点：每 10 万字约 1000-2000 字；六本实测落点 3900-5500 字符，偏上限属正常）。硬标准是覆盖率，不是字数。
- **覆盖率硬标准**：全书每条重要主张、每个关键概念、每条承重案例/情节线、作者的核心处方或结论，digest 里都要有落点——漏一条重要内容即不合格。
- 反向硬标准：任何一段不得是章节复读或 level1 的复制粘贴——那是没煎过的水。

## 骨架（可调，叙述为主，子标题 ≤5 个）

1. **定位**：这本书在做什么、在类型/思想谱系的位置（1-2 段）
2. **主线**：核心主张与论证（或叙事）主线，按书的内在逻辑重组，不逐章复述
3. **全景**：重要概念、案例/情节、结论的完整覆盖——每个 1-3 句，讲清「是什么 + 为什么重要」
4. **边界**：红队与反方最重要的发现压缩进叙述——哪些站得住、哪些被后续研究或史料削弱，保留限定词（不把「疑」写成「伪」，也不把「疑」藏起来）
5. **坐标**：宇宙位置与相邻书目（1 段）

## 写作纪律

- **因果链与关键数字必须带 [原文·L行号]——无行号的机制描述即脑补嫌疑**（实战教训 2026-09-17：许霆案威慑机制方向凭摘要脑补写反、7410 小时时间锚点错位，均因 digest 未引行号，向下游传播 7-8 个文件后被评审组抓出）。digest 定稿前主 agent 自查一遍：每条因果链回原文核对方向，每个数字回原文核对量纲与时间锚点
- 反 AI 腔与全角标点纪律沿用润色 spec；digest 是中间产物，标点脚本不必跑（最终交付物上跑）
- 信源标注沿用 `[原文·章节]` 体例，但密度低于 level1——只在关键论断与承重案例处标
- 从 level1 与测绘图提炼，无必要不回 fulltext.md 重读（防 token 失控）——**但机制方向与数字例外，必须回原文**（见第一条）
- 执行方式：主 agent 自写，或派 1 个子 agent 承做（prompt 自带 level1.md、book-map 路径与本规范要点），主 agent 按下述自检清单验收

## 自检（写完必过，四条全绿才算完成）

1. 拿目录/测绘图逐项对照：全书每个重要部分在 digest 里都有落点吗？
2. 逐段扫一遍：有没有一段是 level1 的复制粘贴或章节复读？
3. 没读过 level1 的人能顺着读完、并复述出全书骨架吗？
4. 批判部分是否保住了限定（量级、置信度、争议状态）？
