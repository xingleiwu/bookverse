# Step 6 · Take away（传播物料）

一切产出遵循润色 spec 的表达纪律（反 AI 腔、全角标点）。素材基础是 `03-synthesis/digest.md`（细节回 level1 / 02-analysis 查证），不从原文或 level1 直接压缩。

## 评审闸门（强制，先于标点检查、先于交付）

每个产物初稿完成后，**必须**按 references/review-panel.md 过三角色评审组——**内容质量专家 + 对应渠道/产物专家 + 去AI味专家（每个产物必含）**——全部 PASS 后才跑标点检查与交付；评审意见落盘 `06-takeaway/review-log.md`。用户说「全自动」时评审不省略，只静默执行。

交付前**必须**跑：

```bash
python3 <skill目录>/scripts/check_punctuation.py <待交付文件...> --fix
```

## 0. 类型菜单（`--takeaway a,b,c` 可选，逗号分隔）

| 类型 | 文件 | 默认 | 说明 |
|---|---|---|---|
| napkin 餐巾纸 | napkin.md | ✅ | 一句话+公式+草图+钩子 |
| brief 主旨总结 | brief.md | ✅ | 一页纸结构化总结，**带 YAML frontmatter，是 MCP 引用的数据源** |
| principles 指导方针 | principles.md | ✅ | 条件→行动→失效场景的行动准则表 |
| xhs 小红书版 | xiaohongshu.md | ✅ | 金句短评+标签 |
| moments 朋友圈版 | moments.md | ✅ | 1-3 句 |
| talk 讲书脚本 | talk-script.md | ✅ | 一分钟口播 |
| handbook 学习手册 | handbook.md | knowledge 类默认，其他显式指定 | 独立可用的学习路径+概念卡+练习 |
| review 书评 | （step 5 产物） | — | 已在 step 5 完成，此处不重复 |

`--takeaway minimal` = 只要 napkin + xhs；`--takeaway all` = 全部含 handbook。

## 1. 餐巾纸极限压缩 → 06-takeaway/napkin.md

```markdown
# 《书名》· 餐巾纸
## 一句话
（≤30 字，说出这本书的灵魂。不用对仗，不喊口号）
## 公式（双风格，`--formula add|mul|auto`，默认 auto）
- **乘法**：`<概念> = A × B × C`（fiction 默认。例：悲剧 = 高贵 × 命运 × 不可抗 × 选择）
- **加法**：`《X》= 主张 + 路径 − 陷阱`（ideas/knowledge/practical 默认。例：《讲义》= 价格机制 + 事与愿违清单 − 市场失灵盲区）
- auto 规则：fiction → mul；其余 → add
## 草图
（Mermaid graph/flowchart，≤8 个节点：全书结构一图流）
## 三个记忆钩子
（合上书一周后还能想起的三样东西：一个场景/一个论断/一个意象…）
```

## 1.5 讲书脚本 → 06-takeaway/talk-script.md

300 字一分钟口播稿，樊登四层结构：**坡道**（一个钩子问题/场景）→ **背景**（这本书是什么来历）→ **论点**（1-3 个核心主张，各配一个案例）→ **升华**（留一个开放问题，不总结教益）。语言按润色 spec 反 AI 腔纪律；口播语域可比书面略口语。

## 2. 小红书版 → 06-takeaway/xiaohongshu.md

- 正文 150-300 字，金句短评风格（开头钩子、结尾留白），遵循润色 spec 反 AI 腔纪律
- **首行提醒用户**：小红书不渲染 Markdown 标题，发布时手动输入纯文字
- 标签规则（严格执行）：
  - 10 个标签：领域精准标签为主 + 书名/作者/译者等搜索直达
  - 不用 `#读书笔记` `#阅读` `#书评` 类泛流量标签
  - 避免「女性」字眼标签
  - 不挂关联弱的名人标签与出版社标签；不蹭时代/大词标签；不挂 `#书单`
  - 作者非大众熟知人物 → 不带作者名标签
  - 标签须核实作品真实属性（题材、国别、类型词要准）
- 成稿展示：正文 + 标签行，用户可直接复制

## 3. 朋友圈金句版 → 06-takeaway/moments.md

- 1-3 句，口语化但保留质感；结尾不带总结教益句
- 给 2 个候选（一走心一克制），用户自选

## 4. brief 主旨总结 → 06-takeaway/brief.md

一页纸结构化总结，从 digest 再压缩而来（叙述版全貌在 digest，此处是结构化数据源），用于快速回忆与外部引用。**frontmatter 是 MCP 服务器（reading-universe）的数据源，字段必须完整**：

```markdown
---
title: 书名
author: 作者
type: 主类型
core-claim: 一句话核心主张（≤40 字）
themes: [主题词]
concepts: [概念名，与宇宙概念节点对齐]
source-book: <slug>
---
## 核心主张
（2-3 句，含"这本书最想让你相信什么"）
## 论证骨架
（3-5 条：主张→支撑方式，一行一条）
## 适用边界
（这本书在哪些场景/问题上是好工具，哪些场景失效——引红队与反方结论）
## 反方要点
（最强反对 2-3 条，一行一条）
## 值得引用
（3-5 条金句，带出处；供 MCP cite 工具返回）
## 与宇宙的连接
（相关概念节点 + 相邻书目）
```

## 5. principles 指导方针 → 06-takeaway/principles.md

把"可迁移"清单转化为**可执行的行动准则**。每条格式：**条件 → 行动 → 失效场景**（失效场景必填——无失效场景的原则是鸡汤）：

```markdown
# 《书名》· 指导方针

| # | 条件（什么时候用） | 行动（怎么做） | 失效场景（什么时候别用） | 出处 |
|---|---|---|---|---|
| P1 | 评估任何政策/规则时 | 写两栏：意图 vs 机制推演（人们会怎么对策） | 系统性认知偏差主导选择时（行为经济学警告） | [原文·章节] |
```

- 知识/思想类：8-12 条；fiction 类转为"叙事技法清单"（同样三列：条件→技法→失效）；practical 类转为"操作守则"
- 从 02-analysis 各专家的"可迁移"节 + 03-synthesis 思维模型卡提炼，不无中生有

## 6. handbook 学习手册 → 06-takeaway/handbook.md

把 curriculum.md（课程设计）转化为**独立可用的学习手册**——读者不需要再看拆解全档也能照着学：

```markdown
# 《书名》· 学习手册
## 这本手册怎么用（3 行说明）
## 学习路径（依赖排序 + 精读/略读标注 + 三种人群走法）
## 概念卡（每张：概念 | 一句话定义 | 应用场景 | 常见误用）
## 练习清单（每章：练习 + 产物 + 自检标准）
## 难度地形（哪里会卡住 + 怎么过）
## 自测（10 题：能答出 = 学到位）
```

## 交付格式

按类型菜单汇报实际产出的文件清单 + 餐巾纸全文预览 + brief 核心主张预览 + 小红书正文预览 + 评审组结论摘要（三角色 PASS 情况，FIX/FAIL 处置见 review-log.md）；提醒：以上均已通过评审组与标点检查；如书评未定稿，说明 takeaway 引用书评的版本号。brief.md 的 frontmatter 会同步进入 MCP 服务器（reading-universe）的检索范围。
